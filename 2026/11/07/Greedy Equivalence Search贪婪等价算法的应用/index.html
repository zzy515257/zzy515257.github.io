你的理解抓住了核心：通过尝试修改图的结构，选择能让评分提高最多的操作，逐步得到更好的图。 但“逐个节点依次加边、删边、反转边”还需要作两点修正：它通常每轮比较所有合法候选操作，选最好的一个；而且它搜索的是图的等价类。

先核对一下名称：这篇论文第 4.2 节、公式（2）—（3）写的是 GIES（Greedy Intervention Equivalence Search，贪婪干预等价搜索）的一种变体。下面先解释 GES 的基本原理，再说明 GIES 的区别。原文来源：:codex-file-citation{path=”F:/学习笔记/论文学习/论文合集/2024_CIKM_CausalMed_lixiang/2024_CIKM_CausalMed_lixiang.pdf” purpose=”source”}

1．“贪婪”是怎样选操作的？

假设有三个变量 (A,B,C)，当前图没有边。算法会评估当前阶段中所有合法的候选加边操作，计算：

[
\Delta S=S(\text{修改后的图})-S(\text{当前图})
]

假设得到下面的增分，数字仅用于演示：

候选操作 分数增量
加入 (A\to B) (+12)
加入 (A\to C) (+5)
加入 (B\to C) (+8)

这一轮选择 (A\to B)，因为它增分最多。

更新图之后，重新评估候选操作，再选一次。 不能直接按 (12、8、5) 的顺序把边都加上，因为加入第一条边后，其他操作的增分可能改变。

所以，如果你说的“依次尝试”是指程序逐一计算候选操作的分数，这个理解是对的；但如果是“处理完节点 (A) 就固定它，再处理节点 (B)”，就不准确了。

2．分数到底怎么算？

论文给出的形式是：

[
S(G,U)=\sum_{i=1}^{n}s\bigl(X_i,\mathrm{Pa}_G(X_i)\bigr)
]

这里：

  • (U)：数据所提供的变量分布信息。
  • (\mathrm{Pa}_G(X_i))：图中指向 (X_i) 的父节点集合。
  • (s(X_i,\mathrm{Pa}_G(X_i)))：根据数据，评价“用这些父节点解释 (X_i)”的局部分数。

整张图的分数，就是各个节点局部分数的总和。

以在一个 DAG 中加入 (A\to B) 为例：改变的是 (B) 的父节点集合，因此可以只计算：

[
\Delta S=
s\bigl(B,\mathrm{Pa}_G(B)\cup{A}\bigr)
-
s\bigl(B,\mathrm{Pa}_G(B)\bigr)
]

其他节点的局部分数相减后抵消，不必重新计算整张图。这种可分解性让搜索更高效。

一种常见的评分方式是取“越大越好”的 BIC 形式：

[
S(G)=
\underbrace{\log P(D\mid\hat\theta_G,G)}_{\text{对数据的拟合程度}}
-
\underbrace{\frac{k_G}{2}\log N}_{\text{模型复杂度惩罚}}
]

其中 (N) 是样本量，(k_G) 是自由参数个数。加边可能提高拟合程度，但通常也增加参数；只有前者的收益超过后者的惩罚，才值得加。

这篇论文没有展开 (s) 的具体计算公式，因此这里的 BIC 是解释算法的常见示例，不能直接认定为论文实际使用的评分。

3．加边、删边、反转边，是混在一起尝试吗？

经典 GES 通常分为两个阶段：

阶段 每轮做什么 何时结束
前向搜索 选择增分最大的合法插入操作 没有插入操作能继续增分
后向搜索 选择增分最大的合法删除操作 没有删除操作能继续增分

通常从空图开始，也可以有指定初始结构。合法操作需要满足无环性等条件；在等价类表示中，还需要检查相应的合法性条件，并更新边的定向。

经典 GES 没有单独的“反转边阶段”。 论文提到的 GIES 则增加了 turning（转向）阶段，用于搜索方向上的改进。它可以直观理解为尝试调整边的方向，但严格来说是作用于等价类的操作，比直接把一个箭头反过来更复杂。

论文只说采用了 GIES 的变体，没有详细列出该变体的操作规则。

4．为什么名字里有“等价”？

因为不同方向的图，有时表达完全相同的条件独立关系。例如：

这三个图都表达：

[

]

它们属于同一个马尔可夫等价类。在标准观测数据设定和评分等价的评分下，不能仅靠这种分数把它们区分开。

GES 因此把这一组图作为一个搜索状态，通常用 CPDAG 表示：确定的方向画箭头，尚不能确定的方向保留无向边。它并不是先把某个 DAG 的所有方向固定下来，再围绕它搜索。

(N) 样本数
( P

具体而言，先拟合：

[
X_i=\beta_0+\sum_{X_j\in P}\beta_jX_j+\varepsilon_i
]

再计算：

[
\mathrm{RSS}_i(P)
=
\sum_{r=1}^{N}
\left(
x_i^{(r)}
-\hat\beta_0
-\sum_{X_j\in P}\hat\beta_jx_j^{(r)}
\right)^2
]

父节点能让预测误差下降，拟合分数就提高；父节点越多，惩罚也越大。 这里省略了不影响结构比较的常数，所以数值不必与其他软件输出的 BIC 一致，仍然是越大越好。

第一，BIC 的统计性质与贪婪算法的搜索性质要分开。

输入虽然是 0/1，默认评分仍然是线性高斯 BIC。

用父节点 (P) 预测节点 (X_i)：

[
X_i=\beta_0+\sum_{X_j\in P}\beta_jX_j+\varepsilon_i
]

回归后得到残差平方和：

[
\mathrm{RSS}_i(P)
=
\sum_{r=1}^{N}(x_i^{(r)}-\hat x_i^{(r)})^2
]

底层用于结构比较的局部分数为：

[
s(i,P)=
-\frac N2
\left[
1+\ln\frac{\mathrm{RSS}_i(P)}N
\right]
-\frac{\ln N}{2}(1+|P|)
]

这里全部当作观测数据，因此各节点使用矩阵中的样本行。

只改变 Diag_1 的父节点集合，因此只比较：

[
\Delta S=
s(\mathrm{Diag}_1,P\cup{\mathrm{Diag}_0})
-s(\mathrm{Diag}_1,P)
]

对于增加一个父节点，还可以写成：

[
\boxed{
\Delta S=
\frac N2\ln
\frac{\mathrm{RSS}_{\text{原来}}}
{\mathrm{RSS}_{\text{加边后}}}
-\frac12\ln N
}
]

例如，假设：

[
N=200,\qquad
\mathrm{RSS}_{\text{原来}}=50,\qquad
\mathrm{RSS}_{\text{加边后}}=18
]

那么：

100\ln\frac{50}{18}
-\frac12\ln200
\approx99.516
]

说明这条边能显著降低预测误差，收益大于复杂度代价。
