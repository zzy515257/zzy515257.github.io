Enhancing Precision Drug Recommendations via In-Depth Exploration of Motif Relationships

一.摘要

1.以前研究的不足：

1.以前的方法用SMILES序列和原子连接图表示药物，经常忽视药物分子中具有特定生物学功能的化学子结构之间错综复杂的合作关系

2.近期的方法没有明确提出在药物分子中具有特定生物学功能的化学子结构与病人病情演化之间进行建模

2.DEPOT的创新

DEPOT（drug recommendation via in-depth exploration of motif realationships)用具体的化学知识键药物分子转换为功能团树，并将其与提出的结构意识图转换器相结合，高效的捕捉长距离的功能团的共同影响。

1.不像以前方法，DEPOT不仅考虑了结构信息和药物功能团之间的相互作用，他还从循环和探索两个独特的视角挖掘了功能团之间动态的关系和疾病的进程。

2.采用了历史DDI作用序列

$q^u$表示各种疾病

模型使用变分自动编码器建模分布，而不是直接利用$q^u$作为表示向量，这种做法可以固定训练减轻噪音，而且可以加入不确定性到表示中

Variational Autoencoder（变分自编码器，简称 VAE） 是由 Kingma 和 Welling 在 2014 年提出的一种经典深度概率生成模型（即论文引用的参考文献 [47]）。对比传统自编码器，可以很清楚地看懂它的核心思想：

1. 先看普通自编码器（Autoencoder, AE）

  • 结构：输入 x -> 编码器（Encoder）-> 固定潜向量 z -> 解码器（Decoder）-> 重构输出 x'。
  • 特点：编码器把输入 $x$ 压缩成潜空间里的一个确定性的点 $z$。
  • 局限：潜空间里每个样本只占一个孤立的点，点与点之间的空白区域缺乏规律，鲁棒性差；输入带有一点噪声，编码出来的点就可能偏到未知区域。

2. 再看变分自编码器（Variational Autoencoder, VAE）

VAE 的核心突破，是把潜空间的表示从“一个确定性的点”改造成了“一个连续的概率分布”：

  1. 概率编码器：给定输入 $x$，编码器不再直接输出向量 $z$，而是输出一个高斯分布的两个参数——均值向量 $\boldsymbol{\mu}$（分布中心）和标准差/方差 $\boldsymbol{\sigma}$（不确定性范围）。

  2. 重参数化采样（Reparameterization Trick）：为了既能从高斯分布 $\mathcal{N}(\boldsymbol{\mu}, \text{diag}(\boldsymbol{\sigma}^2))$ 中随机采样出潜向量 $z$，又能让梯度正常反向传播，VAE 改写采样过程为：

    这样随机性完全落在外部标准正态噪声 $\epsilon$ 上，$\boldsymbol{\mu}$ 和 $\boldsymbol{\sigma}$ 对损失函数是可导的。

  3. 标准 VAE 的双项损失（ELBO）：

    • 重构损失：要求解码器用采样出的 $z$ 仍能还原出原始输入 $x$（哪怕 $z$ 在 $\boldsymbol{\mu}$ 附近有随机抖动），从而强迫模型抵抗噪声、学习平滑的局部特征；
    • KL 散度正则项：迫使编码器学出的分布 $\mathcal{N}(\boldsymbol{\mu}, \boldsymbol{\sigma}^2)$ 靠近标准正态分布 $\mathcal{N}(0, I)$，防止分布坍缩（例如把 $\boldsymbol{\sigma}$ 压成 $0$ 退化回普通 AE）。

3. 严谨区分：这篇论文（DEPOT）实际用了 VAE 的哪一部分？

核对论文的架构与损失函数可以发现，DEPOT 并没有搭建完整的 VAE，而是只借用了 VAE 的“概率编码器 + 重参数化采样”这一半机制：

作者在论文中解释引入这一机制的动机是：真实医疗场景中病情演变往往存在动态性与随机不确定性，直接拿硬算出来的差值向量 $\mathbf{q}^u$ 做匹配容易受电子病历噪声干扰；通过建模高斯分布并采样，可以把不确定性融入表征中，从而缓解噪声并稳定训练。

->公式的含义:

1.$\mathbf{q}^u = \text{ReLU}(\mathbf{W}_u \mathbf{q}^u)$：对原始病情差值做一次线性变换（乘以可学习矩阵 $\mathbf{W}_u$）和 $\text{ReLU}$ 非线性激活。这里等号左右都写了 $\mathbf{q}^u$，属于论文常见的原地覆盖写法（相当于代码里的 q = F.relu(W_u(q))）。

而且，正态分布的线性变换依然服从正态分布。因此，只要按照 $\mathbf{z}^u = \boldsymbol{\mu} + \epsilon \odot \boldsymbol{\sigma}$ 这样去构造 $\mathbf{z}^u$，无论 $\boldsymbol{\mu}$ 和 $\log \boldsymbol{\sigma}$ 前面是用线性层、MLP 还是任何其他网络算出来的，随机变量 $\mathbf{z}^u$ 的概率分布就严格等于 $\mathcal{N}(\boldsymbol{\mu}, \text{diag}(\boldsymbol{\sigma}^2))$——$\boldsymbol{\mu}$ 在数学上就是 $\mathbf{z}^u$ 分布的均值，$\boldsymbol{\sigma}$ 就是它的标准差（$\boldsymbol{\sigma}^2$ 是方差）。

2.$\boldsymbol{\mu} = \mathbf{W}_\mu \mathbf{q}^u$ 与 $\log \boldsymbol{\sigma} = \mathbf{W}_\sigma \mathbf{q}^u$：分别用两个可学习矩阵 $\mathbf{W}_\mu$ 和 $\mathbf{W}_\sigma$，映射出高斯分布的均值向量 $\boldsymbol{\mu}$ 和对数尺度向量 $\log \boldsymbol{\sigma}$（文字中说明 $\boldsymbol{\mu}$ 和 $\boldsymbol{\sigma}$ 分别代表均值和方差，不过按下一行公式的数学定义，实际乘在 $\epsilon$ 上的是标准差）。

3.$\mathbf{z}^u = \boldsymbol{\mu} + \epsilon \odot \boldsymbol{\sigma}, \; \epsilon \sim \mathcal{N}(0, I)$：从标准高斯分布 $\mathcal{N}(0, I)$ 中采样随机噪声 $\epsilon$，与 $\boldsymbol{\sigma}$ 逐元素相乘（$\odot$）后加到均值 $\boldsymbol{\mu}$ 上，最终得到融合了临床不确定性的病情演变表征向量 $\mathbf{z}^u$。

权衡系数 $\alpha$ 并非固定常数，而是根据过去固定长度 $T$ 步的历史平均 DDI 率 $\kappa$ 与预设目标 DDI 阈值 $\eta$ 的差距动态调整：

  • 当 $\kappa \le \eta$（安全达标）：$\alpha = 1$，安全性损失权重 $1-\alpha = 0$，模型完全专注于优化推荐准确率。
  • 当 $\kappa > \eta$（风险超标）：超标幅度 $\kappa - \eta$ 越大，$\tanh\left(\tau \frac{\eta}{\kappa - \eta}\right)$ 的值越小，从而自动压低 $\alpha$、增大安全性权重 $1-\alpha$，强化对 DDI 的惩罚。其中温度参数 $\tau$ 控制非线性调节的陡峭程度（实验中较优参数为历史窗口 $T=3$、温度 $\tau=0.08$）。
  • 相比传统方法的改进：以往方法（如仅依据当前单批次 DDI 率做线性调整）容易受单次异常样本波动干扰；DEPOT 改用历史窗口均值 $\kappa$ 与 $\tanh$ 非线性映射，让训练过程更平滑稳定，同时在准确性与安全性之间取得更优平衡
